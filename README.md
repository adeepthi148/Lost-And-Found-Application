# Lost and Found Application

## About the Project

Losing personal belongings such as ID cards, books, keys, wallets, and bags is a common problem in colleges and public places.

Our Lost and Found Application provides a centralized platform where users can report lost or found items, search for items, and manage their reports easily.

## Features

- **User Authentication:** Register and log in.
- **Report Lost Items:** Report items that have been lost.
- **Report Found Items:** Report items that have been found.
- **Search Items:** Search for lost and found belongings.
- **Manage Reports:** View and manage personal reports.
- **Recovery Status:** Mark lost items as recovered and found items as returned.
- **Delete Reports:** Permanently delete reports.
- **User Dashboard:** Access application features and recent reports.
